# Peggy 運動內容 🏋️‍♀️🌸

專為 Peggy 量身打造的粉白少女風健身紀錄與月曆打卡網頁應用。

## ✨ 主要特色
- 🔒 **PIN 碼密碼鎖**：專屬 PIN 碼保護（預設：`0817`）。
- 📅 **互動月曆視圖**：支援觸控左滑右滑手勢切換月份，有運動紀錄的日期會標記可愛的運動打卡圖示 `🏋️‍♀️`。
- 🌸 **本月運動天數統計**：頂部即時統計當月運動天數看板與元氣金句。
- ✍️ **每日運動詳情卡片**：記錄動作名稱、重量、組數、次數與備註。
- 📸 **拍照自動判斷器材**：支援手機拍照/相簿上傳，智能辨識健身器材並推薦配重與組數一鍵套入。
- 💾 **離線資料保存**：所有運動紀錄自動保存在瀏覽器 LocalStorage。
- 📋 **一鍵複製純文字**：隨時複製紀錄貼給 AI 助理進行分析或備份。
